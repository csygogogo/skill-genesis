# 项目代码风格

- 这是个人实验工具，优先简单、直观、容易手工维护的实现。
- 使用普通函数和少量清晰的模块，避免复杂类体系、冗余状态和不必要封装。
- 历史记录用普通文件夹、JSON/JSONL 和 Markdown 保存；不要自行引入数据库、ORM 或外部队列服务。
- 保留现有功能，后端语法兼容 Python 3.10，路径和启动命令兼顾 Windows / Linux。
- 前端关闭不影响后端保存记录；不要将浏览器缓存作为历史记录的唯一来源。

- 用户只需 `python app.py` 启动前后端；入口代码禁用字节码缓存，不要求用户记忆额外启动参数。
- 使用 Conda 环境 `agent310`（Python 3.10），依赖直接安装到该环境；不要使用项目内 `.test-deps` 或 `pip --target`。
- README 只保留必要的启动、地址和文件说明；不添加环境创建教程、环境变量配置或 CI 工作流。
